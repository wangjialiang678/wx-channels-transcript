# sph-transcript —— 视频号链接 → 逐字稿

## 什么时候用

- 用户贴了 `https://weixin.qq.com/sph/...`，要文字稿
- 用户说「扒一下这条视频号的逐字稿 / 文案」「这条视频讲了什么」
- 需要拆解对标账号的口播内容
- 本地已有音频/视频文件，想转成文字

**不适用**：B站 / YouTube 这类**公开平台**——那些优先「到网上搜现成的字幕」。视频号是微信封闭生态、网上搜不到逐字稿，才走本工具。

## 先跑这一步（每次都可以先做）

```bash
wx-channels-transcript scan
```

它会扫描本机：ffmpeg 有没有、各 ASR 后端的凭证在不在、本地模型装没装，然后**给出推荐并解释为什么**。

**你应该把 scan 的输出读给用户听**——尤其是「推荐哪条路、为什么」，因为这决定了接下来是"零额外步骤"还是要先装东西。

## 主命令

```bash
wx-channels-transcript "<视频号链接>" -o "<输出目录>"
```

成功时 **stdout 只有一行：生成的 `.md` 路径**（便于管道取用），进度全部走 stderr。

### 常用选项

| 选项 | 用途 |
|---|---|
| `-o, --out <目录>` | 输出目录（默认 `./transcripts`） |
| `--save-audio` | 保留音频文件到输出目录 |
| `--audio-format <f>` | 音频格式：`wav`（默认）/ `mp3` / `m4a` |
| `--save-video` | 保留原始视频 |
| `--keep` | 保留全部中间文件 |
| `-t, --to <后端>` | 强制指定后端：`bailian`（默认）/ `volcengine` / `local` |
| `-m, --model <模型>` | 指定模型 |
| `-l, --lang <语言>` | 语言提示，默认 `zh` |
| `--hotwords "<词1,词2>"` | 额外热词（逗号分隔，或给文件路径） |
| `--no-auto-hotwords` | 关闭「从视频标题自动提取热词」（**默认开启**） |
| `--show-hotwords` | 只打印会自动提取的热词，不转写 |
| `--vocabulary-id <id>` | 阿里侧热词表 ID（需先在百炼控制台创建） |
| `--cookie "<字符串>"` | 手工提供元宝 cookie，**完全跳过钥匙串授权** |
| `--browser <名称>` | 指定从哪个浏览器读：`chrome` / `edge` / `brave` / `arc` … |
| `--no-browser` | 禁止读浏览器（只用缓存或 `--cookie`） |
| `--probe` | 只解析拿直链，不做转写（调试用） |
| `--json` | 输出 JSON（便于你解析） |

**默认零中间文件**：不加 `--save-*` 时，跑完只会留下 `.md` 和 `.json`。

**什么时候该建议用户加 `--save-audio`**：用户想拿音频做别的用途时（导入播客 App、二次剪辑、存档）。
但注意——**这会让流程多一次下载 + ffmpeg 转换**，除非用户确实需要，否则不要主动加。

## 热词：默认开启，不用你操心

**工具会自动从视频标题提取专名当热词**——因为视频号标题里往往就写着 ASR 最容易错的那批词：

```
标题：82亿美元，苏姿丰买下李飞飞的 WolrdLabs。#李飞飞 #苏姿丰 #AMD #WorldLabs
自动提取：李飞飞、苏姿丰、AMD、WorldLabs
```

**实测效果**：`苏姿丰` 从「8 对 2 错」变成「**14 对 0 错**」（原本错成"朱志峰"）。

**各后端的热词入口**（都是**零预配置**，不需要建词表）：

| 后端 | 入口 | 上限 |
|---|---|---|
| **阿里 qwen3** | `parameters.corpus.text`，接受**任意文本** | 10,000 tokens |
| **火山 seedasr** | `corpus.context` 的 hotwords 数组 | 5000 词 |
| 本地 | 初始提示词近似 | — |

**所以不需要因为热词去换后端**——两家都零门槛。

> ⚠️ **重要排查经验**：阿里这类接口对**未知参数不报错**。实测 `parameters.context` 会让任务 `SUCCEEDED`，
> 但热词**完全不生效**（输出与无热词逐字相同）。
> **判断参数是否生效，不能看任务成功与否，必须比对实际输出。** 这是最容易误判的地方。

### 其它子命令

| 命令 | 用途 |
|---|---|
| `sph backends` | 列出所有支持的后端；未配置的会给出**配置步骤和官方文档链接** |
| `sph auth` | 查看登录态缓存状态（是否还有效、几天前存的） |
| `sph auth --clear` | 清除缓存，强制下次重新授权 |

## 三层决策逻辑（你应该按这个顺序判断）

### 第一层：ASR 后端选谁

**永远优先云端**。原因不是"云端更好"，而是**云端能省掉整条本地处理链**：

| 后端 | 直链直传 | 直接吃 mp4 | 额外步骤 | 建议 |
|---|---|---|---|---|
| **阿里云百炼** | ✅ | ✅ | **零** | ⭐ 首选（最快） |
| 火山引擎 | ✅ | ✅（**实测**，官方文档未列 mp4） | 零 | 次选（可交叉验证） |
| 本地 whisper | ❌ | ❌ | 下载 + ffmpeg + 本地算力 | 数据不出本机的兜底 |

**关键差异**：阿里云和火山**都能直接吃 mp4**，所以两条路都可以做到「拿到直链 → 直接提交 → 出稿」，**不下载、不转码**。
差别只在速度：阿里明显更快（同一条件下约 3-4 倍）。详细实测数据与样本量见 `docs/benchmarks.md`。

如果本机**没有任何云端凭证**，才考虑本地模型（`sph scan` 会告诉你缺什么、怎么装）。

### 第二层：某个后端不可用时怎么办

**不要自己猜怎么配。** 跑 `sph backends`，它会输出每个后端的：
- 缺什么
- 怎么做（具体命令）
- **官方文档链接**

然后**把官方文档链接给用户**，让他（或他的 Agent）照着做。本工具刻意不在代码里写死注册流程——文档会变，链接不会。

### 第三层：用户不想授权钥匙串

三个选择，按推荐排序：

1. **就授权一次**——说明白的：这是 macOS 系统的安全机制，要输 Mac 登录密码，只读元宝那一个域名的 cookie。**"始终允许"后一个月内不会再问**（有缓存）。
2. **`--cookie "<粘贴的cookie>"`**——从浏览器 DevTools 复制，完全零弹窗。
3. **换用 Firefox 登录元宝**——Firefox 的 cookie 不加密，理论上无需授权（未在代码里实现，作为未来方向）。

## 首次使用会发生什么（要对用户解释）

1. 会弹**一次** macOS 钥匙串授权——**要输入的是 Mac 登录密码**，不是元宝密码、不是 Apple ID
2. 然后自动读取浏览器里元宝的登录态，读到后**缓存起来**（`~/.config/sph-transcript/session.json`，权限 0600）
3. 之后约一个月内直接复用缓存，**不再弹窗、不再碰浏览器**
4. 登录态过期时（`getuserinfo` 返回 401）会自动清除缓存并提示重新授权一次

> 如果用户看到**弹了两次**：那是两个不同程序各自申请了一次（比如之前的工具用的是 Python，这个是 Node）。macOS 的授权是按"申请方二进制"分别记住的。只用本工具的话只会弹一次。

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `在 chrome 里没有找到 yuanbao.tencent.com 的 cookie` | 没登录过元宝 | 用该浏览器打开 `https://yuanbao.tencent.com` 扫码登录 |
| `读取到的 cookie 无法通过元宝校验（HTTP 401）` | 登录态过期 | `sph auth --clear` 后重跑，会重新读取浏览器 |
| `拿不到 export_id` | 视频已删除 / 私密 / 过期 | 换一条链接；这是服务端返回的，不是程序 bug |
| `该链接不受支持` | **视频号直播/回放不支持** | 元宝接口只认已发布视频；要直播需用 MITM 方案（见 docs/backends.md） |
| `没有找到 Chromium 系浏览器` | 用的浏览器不受支持 | 用 `--cookie` 手工提供，或换机 |
| 找不到 ffmpeg 相关报错 | 选了需要转码的后端 | 换 `-t bailian`（无需 ffmpeg），或 `brew install ffmpeg` |

## 重要边界（要说清楚，别让用户误会）

- **不支持视频号直播/回放**。元宝接口只认已发布的视频。
- **走的是非公开接口**。腾讯随时可能调整，届时会失效。代码里做了字段名兜底，但无法免疫。
- **建议用小号**。这是拿元宝账号在调它没对外承诺的接口。
- **数据流向**：链接和元宝 cookie → 腾讯；**音频内容 → 所选云端 ASR（阿里云/火山）**。敏感素材请改本地后端。
- **ASR 输出未经校对**，同音字可能有误。要做精确引用（写稿、引原话）**必须回原视频核对**。
