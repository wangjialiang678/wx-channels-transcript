## 一句话结论

README 写得比同类项目清楚得多——「它解决什么问题」「为什么不装证书」「数据流向」三段是典型的好文档；但它**默认读者已经知道要自己搞一个 ASR Key**，并且把三条 backend 里最重要的一条规则写反了（L73），所以**非开发读者看完仍然不知道该准备什么、第一步从哪开始，且会被 L73 误导**。

## 二、结构问题（含建议的新顺序）

### 现存顺序
它解决什么问题 → 为什么不用 MITM → **快速开始** → 可选音视频 → 自动热词 → 后端对比 → 首次密码框 → 架构 → 数据流向 → 风险 → License

### 问题
1. **「我要准备什么」整段缺失。** L45「快速开始」第一行就是 `wx-channels-transcript scan`，但读者此刻还不知道：要不要注册账号？要不要花钱？Key 从哪来？这个信息只在 L137 一行「配置方法见 docs/backends.md」——**埋在整篇 3/4 处**，而且是「链接」不是「内容」。
2. **「首次会弹密码框」这个最能让读者安心的段落排在 L139。** 读者 A 最怕的就是「它要我输密码，是不是要盗号」——这段应该紧跟快速开始，或至少在快速开始里先给一句预告 + 锚点。
3. **热词段（L80-117，38 行）与后端段（L121-137）挤在一起**，两部分都在讲「参数/接口细节」，属于实现层，读者第一次使用时完全不需要。而真正需要的「我怎么拿到 Key」被压到最后。
4. **「风险与边界」（L186-192）在最末尾**，但其中「建议用小号」「依赖非公开接口」是**读者决定要不要用之前**就该知道的。
5. **L33-43 的 MITM 对比放在快速开始之前**——读者还没决定要不要用，就先读了 10 行竞品分析。属于「作者想讲」而非「读者要看」。

### 建议的新顺序
1. 一句话简介 + 一条最小命令（保留现有 L3-7，但删掉时效数字）
2. **它解决什么问题**（保留 L11-19，压缩）
3. **你需要在开始前准备什么**（**新增**：① Node ≥ 22；② 浏览器登录过元宝；③ 一个 ASR Key（含「要花多少钱」一句话）；④ 仅 macOS 支持读浏览器 cookie）
4. **快速开始**（保留 L45-55，补上「第一步：拿到 Key → docs/backends.md」）
5. **第一次运行会发生什么**（把 L139-148 提前到这里，并改写为「读完这段再动手」）
6. **能力与边界**（把 L186-192 的风险 + L43 的直播不支持合并前置）
7. 选题/进阶：热词、保留音视频、后端对比（L57-137，压缩后）
8. 数据流向（L176-184）
9. 架构与设计原则（L150-174 → 拆走，见第四节）
10. License + 文档索引（troubleshooting / backends / research）

## 五、AI Agent 友好度问题

| 问题 | 位置 | 说明与改法 |
|---|---|---|
| **命令形式三处不一致** | README `wx-channels-transcript` / `sph` / SKILL.md `wx-channels-transcript` | Agent 无法确定该跑哪个。**统一为一条**：在 README 顶部定义一次 `wx-channels-transcript`（或建议 `alias sph='node .../bin/sph.mjs'`），全文只用一个形式。 |
| **面向 Agent 的入口没有标注** | L166 | README 只在文件树里写「skill/SKILL.md 给 AI Agent 用」。Agent 未必会往下读文件树。**建议在 L9 分隔线下方加一行**：「> 如果你（或你的 Agent）要直接执行：读 `skill/SKILL.md`，那里有决策顺序与排错表。」 |

| **「先问用户」的边界不明确** | L141-148 / SKILL.md L132-138 | 全程没有一句明确写「读取浏览器 cookie 前应先告知用户」。macOS 弹窗是系统行为，不等于 Agent 已获授权。**建议在 README 加一条硬约束**：「Agent 在触发浏览器 cookie 读取前，必须先向用户说明将读取元宝登录态并可能弹出系统密码框；用户拒绝时改用 `--cookie` 或 `-t local`。」 |
| **README 无「失败 → 原因 → 处置」映射** | 全文 | Agent 排错必须跳 `docs/troubleshooting.md`，而 README 根本没链它。**建议**：README 加一张 5 行速查表（cookie 找不到 / 401 / 拿不到 export_id / 不受支持 / 缺 ffmpeg），或至少给 troubleshooting.md 一个显眼链接。 |
