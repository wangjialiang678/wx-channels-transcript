# 实测数据

> ⚠️ **读之前请先看这段**：下面所有数字都是在**一台机器、一条视频、一次运行**的条件下测出来的。
> 换网络、换机器、换音频长度，结果都会变。**请把它们当量级参考，不要当验收标准。**
>
> 实测当时的具体条件记录在每节开头。价格会随官方调价变化，**一律以官网为准**。

---

## 测试条件

| 项 | 值 |
|---|---|
| 机器 | Mac（Apple Silicon），家用宽带 |
| 样本视频 | 一条 433 秒（7 分 13 秒）中文口播，含较多英文专名 |
| 音频 | 16kHz 单声道，13.2 MB |
| 视频文件 | 23 MB |
| 样本量 | **1 条** |

> **样本量是这份数据最大的弱点。** 所有对比结论都来自同一条视频——它有代表性（典型的 AI 口播内容），
> 但**不能代表所有视频**。特别是「哪家识别更准」这类结论，单条样本远远不够。

## 一、端到端耗时

| 环节 | 耗时 |
|---|---|
| 解析（2 个接口调用） | 约 0.4 秒 |
| 转写（阿里云百炼 `qwen3-asr-flash-filetrans`） | 约 8.7 秒 |
| **合计** | **约 9 秒** |

**同样这条视频，换火山引擎后端**：

| 环节 | 耗时 |
|---|---|
| 解析 | 约 0.4 秒 |
| 转写（`volc.seedasr.auc`，模型 2.0） | 约 34.5 秒 |

→ **阿里明显更快**（约 3-4 倍）。这与命名相符：阿里那个模型叫 `flash`，火山标准版官方自称"返回时间：适中，3h 内返回"。

**本地文件模式**（跳过解析）：约 7.4 秒（含上传 13 MB 音频）。

## 三、专名识别准确率

**判据设计**：挑出 14 个「英文专名 + 中文同音字」作为判定点（如 `苏姿丰`、`李飞飞`、`World Labs`、
`ChatGPT`、`ImageNet`、`Atlas`、`Chiplet`、`CES`、`MIT`、`第一性原理` 等），统计正确写法与常见错误写法各出现几次。

| 模型 | 专名准确率 | 典型错误 |
|---|---|---|
| `qwen3-asr-flash-filetrans`（阿里） | 92.9%（39 对 / 3 错） | 仅 `World Lab` 脱尾 s、`B性原理` |
| `volc.seedasr.auc`（火山 2.0） | 93.0%（40 对 / 3 错） | `AI教母→AI酵母` |
| `paraformer-v2`（阿里，**已从代码移除**） | 10.5%（4 对 / 34 错） | `李飞飞→李飞霏`、`苏姿丰→苏之峰/朱之峰`、`ChatGPT→恰恰的gt`、`MIT→卖毕业` |

### 这三个数字该怎么读

1. **阿里 vs 火山：差距 0.1 个百分点，统计上等于平手。** 不要据此说"A 比 B 准"。
   两家的错误甚至高度重合——**都把 `苏姿丰` 写成过"朱志峰"**。
2. **paraformer 的 10.5% 是架构代际差异，不是"这个模型差"。**
   它是传统 ASR 的巅峰（AISHELL-1 CER 1.95%，优于 Whisper），但**没有世界知识**——
   听清 `/sū zī fēng/` 没问题，不知道"苏姿丰"是个人名。所以遇到专名会崩。
   而大模型 ASR（qwen3 / seedasr）能用世界知识纠正。
3. **这是「专名 + 同音字」专项测试，不是整体字准确率。** paraformer 的中文句子大部分是对的，
   只是在专名上全军覆没。但**对口播文案来说，专名错了整篇就不能用**。

### 热词的效果

给 ASR 喂入热词后（从视频标题自动提取）：

| 专名 | 无热词 | 有热词 |
|---|---|---|
| `苏姿丰` | 8 对 / **2 错** | 14 对 / **0 错** |
| `AI教母` | 0 对 / **1 错** | 1 对 / **0 错** |

`AI教母` 并**不在**热词列表里（标题中没有它），却被一并纠正——说明 `corpus.text` 不只做词表匹配，
**还向模型提供了领域上下文**，整体识别倾向都变好了。

## 四、一个可能变更的第三方行为

**火山引擎的录音文件识别能吃 mp4**——这是实测结论，**官方文档的格式白名单里并没有 mp4**
（写的是 `wav / mp3 / ogg / spx / amr / aac / m4a`）。

服务端显然做了容器兼容（mp4 与 m4a 同属 ISO BMFF，读的是内部音轨）。但**这是未承诺的行为**，
随时可能被收紧。若失效，请以官方文档为准，并改用「先抽音频」的路径。

## 五、复现实验的方式

```bash
# 用你手头任意一条视频号链接，跑一遍并计时
time wx-channels-transcript "<链接>" -o /tmp/bench

# 强制指定后端做对比
time wx-channels-transcript "<链接>" -t volcengine -o /tmp/bench-volc
```

想得到**有统计意义**的结论，请用 ≥30 条自己的视频跑，而不是相信上面这些单样本数字。
